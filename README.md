# python-event-driven-architecture
A learning repo about EDA in python using pydantic basemodels for strongly typed events

## Setup

This project uses [uv](https://github.com/astral-sh/uv) for dependency management and packaging.

To install the project dependencies and the `peda` package locally:

```bash
uv sync
```

You can run scripts or tests in the isolated environment using:

```bash
uv run python <script_name.py>
```
